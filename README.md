# Odin 3 Desktop (`odin3_desktop`)

AYN Odin 3 专属掌机客户端与桌面增强应用。

## 核心功能规划

1. **全新手柄友好 UI & 桌面启动台**
   - 适配 Odin 3 实体手柄（D-Pad / 摇杆 / ABXY）焦点导航。
   - 分 Tab 展示与管理应用，支持 Tab 的增删改查、应用归类与快速启动。
2. **通知栏 / 快捷开关【息屏挂机】（OLED 防烧屏）**
   - 注册系统下拉 Quick Settings Tile 与常驻通知快捷入口。
   - 纯黑浮层（`#000000`）降低功耗，动态像素微位移（Pixel Shift）防烧屏，支持后台保活与防误触解锁。
3. **后台进程强杀**
   - 解决重型模拟器退出后再次进入黑屏死机问题。
   - 支持配置一键强杀列表，通过 Shizuku / Root 实现静默强杀。
4. **充电风扇智能调度**
   - 监听电源连接与前台运行状态。
   - 充电且无白名单游戏运行时，默认关闭风扇或切换为静音挡；进入游戏自动恢复散热模式，具备过热硬保护机制。
5. **系统原生侧滑替换**
   - 提供关闭/接管原厂 `com.odin.gameassistant` 侧滑悬浮条的无侵入方案。
