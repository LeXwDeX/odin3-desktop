## ODIN-20260905-01：Dock 风扇、性能无法操作

- 记录日期：2026-09-05。
- 状态：待排查；本次仅记录用户反馈。
- 用户反馈：今天无法操作底部 Dock（用户描述为“docker”）中的风扇、性能功能，出现大意为“ADB 没连接，无法访问硬件服务”的提示。提示文字为用户转述，尚未取得完整原文。
- 影响：用户无法通过桌面的这两个入口调整硬件。
- 待确认：发生时的应用版本、是否重启过设备、ADB 连接状态、硬件桥的可用性与认证状态，以及完整错误与复现步骤。尚未确定根因，也未确认是否与此前修复有关。

后续处理与验收：

- 确认导致服务不可访问的实际环节，并给出与实际故障相符、用户可以执行的恢复提示。
- 服务不可用时如实显示不可用或未读取；操作失败不能保留看似已切换成功的状态。
- 恢复后在实机验证风扇、性能均可操作，界面与硬件读回一致；覆盖设备重启、服务中断与恢复场景，并记录仍存在的使用限制。

已有背景见 [快捷控制的受限硬件后端](quick-controls.md#受限硬件后端) 与 [性能、风扇修复记录](performance-fan-home-fixes.md)。这些历史记录不代表本次问题已经复现或解决。

## ODIN-20260905-02：VIDEO SHADER 如实显示当前游戏的生效状态

- 记录日期：2026-09-05。
- 状态：待核查、待实现；本次仅记录需求。
- 用户要求：诚实显示 VIDEO SHADER 是否能够正确应用到当前游戏，不能显示“开启”，实际却无法开启或使用。
- 用户接受的限制：部分游戏可能因反作弊等限制无法使用滤镜，这是可以接受的；关键是如实告知。不将“反作弊”直接认定为任何一次失败的原因。

后续处理与验收：

- 将保存的启用意愿与当前游戏的实际效果状态分开表达；开关打开、配置保存成功、截图预览成功，都不能单独作为游戏内生效的证据。
- 只有确认所选效果已正确应用到当前游戏时，才显示“已生效”。未生效、不支持、权限不足、应用失败或无法确认时显示相符的状态；原因未核实时明确表示原因未知。
- 如果只支持部分效果或仅有截图预览，明确显示适用范围，不能把兼容遮罩或预览当作全部所选效果已在游戏中生效。
- 切换游戏、返回桌面或运行时失效后及时更新状态，不沿用上一游戏的成功状态。
- 在实机分别验证可生效、不支持或受限制、缺少权限、无法确认与切换游戏的情况，并对照当前游戏实际画面及运行状态。受限制时如实呈现，本需求不要求绕过游戏反作弊。

已有能力与验证边界见 [滤镜移植与验证记录](shader-port.md)。本条不代表已经完成当前游戏兼容性检测或实时效果接入。
