# v0.1.7 UI、英文 README 与 Dashboard 刷新

## 行为

- 首页每个分类最多显示前 10 个应用；超过 10 个时第 11 项为 [+]，打开全部已安装可启动应用。
- 全屏应用页隐藏顶部分类栏、顶部遥测和底部硬件 Dock。现有默认显示配置下一屏 6 列 × 3 行；字体和可用尺寸变化时由布局重新测量。B 返回来源分类及 [+] 位置，弹窗和排序仍先处理自身的返回。
- 中英文和日文通过独立紧凑资源显示底部状态：非中文性能 P1/P2/P3、风扇 OFF/S/M，保留 Q、SYS、— 的实际状态差异；中文保留短中文。无障碍描述使用完整名称。
- Tab 编辑将名称与操作分行，上移/下移使用固定的 ▲/▼ 按钮，保留完整语义和原有可操作限制。翻译较长的其他操作允许换行。设置背景不再透出下层文字，通用应用弹窗的标题与返回提示分别分配宽度。
- Dashboard 的每个采样器进入时立即读数，然后在上次采样完成后等待 6 秒，重复 3 次，之后每次等待 30 秒。旧代码的实时 2 秒、PSS 15 秒、存储 60 秒循环均使用同一节奏。内部存储旧缓存仅用于进入时立即展示，计划采样会重新读取。慢查询不堆积，离开页面取消，再进入重新开始。顶部小型遥测保持原节奏。
- README 改为纯英文，配合本机真实英文应用库、灯光和方向设置截图。自定义中文分类名称与 Wi-Fi 名称不为公开截图改写。

## 本地验证

Debug / Release 构建、完整单元测试和 Android Lint 通过。Dashboard 时间测试检查 0/6/12/18/48/78 秒、离开后取消、再次进入重置，以及慢采样不会并发堆积。图标测试检查 0/9/10/11/20/50 项边界、真实 ViewModel 的网格边缘、隐藏栏位不可进入、弹窗返回与恢复 [+] 位置。

Home/B 返回回归保持 HOME ×100 无额外应用扫描/硬件刷新/可见性工作，根页 BACK ×100 不转交系统。性能和风扇方法级回归通过，多语言 279 个文案键及参数一致；没有变更硬件控制协议。

## 设备验证

2026-09-08，重新确认 Odin3 / Android 15，旧版为 v0.1.6。校验签名后以 v0.1.7 Debug APK 保留数据覆盖测试：

- 使用设备已有 29 个应用验证 [+]、全屏 3 行 18 个图标及 B 返回。6 个应用的分类保留原应用列表，不生成无用的溢出入口。
- 中、英、日界面已查看；日文全屏页另以 1.3 字体检查，长名称可省略，选中项在标题区显示，底部返回入口可见，字体随后恢复 1.0。
- 英文 Tab 的 ▼ 实际将首个分类移至第二位，再用 ▲ 恢复；独立读取数据库确认全部表记录一致，包括 3 个分类与 47 条应用归属记录。
- 灯光与方向设置截图只切换菜单，没有改写对应硬件选项。

设备采样结果不是固定频率的精密计时记录；6/30 秒调度和取消由执行生产采样节奏函数的虚拟时钟测试验证。此轮并非所有屏幕、所有字体倍数的穷尽 UI 审计。
