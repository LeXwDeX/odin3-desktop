# Dashboard

首页最左侧新增固定 Dashboard，与可编辑应用分类分开保存。进程首次启动显示此页；L1/R1 在 Dashboard 与应用分类间循环。现有应用分组、默认分类标记、应用映射和底部船坞继续保留。

宽屏统计区使用共享两列网格：左列存储区域与下方 CPU/GPU 组合共用左右边界，右列运行内存与下方 Wi-Fi 共用左右边界。没有外部存储时左上只显示内置存储；有外部存储时，内置存储与每个已挂载卷各占一张卡片。多个外部卷分行排列，不合并容量；两列随存储行数增加高度，保持下方卡片对齐，页面可滚动。

统计卡片全部只读，不接受点击或手柄焦点，也不显示“A 详情”或“点击授权”。CPU/GPU 卡片显示对应真实温度和统一 0–105°C 温度条，两端标明 `0°`、`105°`。条长限制在范围内，温度数值保留实际读数；读不到时为“— °C”和空轨道。低于 60°C 为青色、60–80°C 为暖色、达到 80°C 为红色，仅作阅读提示，不代表 OEM 温控阈值。本轮不再采样或显示使用率。

页面下方依次是文件管理、系统设置、Odin 设置、滤镜调整四个操作按钮，宽屏等宽排列，窄屏可分两行。内存清理与磁盘清理已经取消。再下方为全局硬件 Dock。Dashboard 的滤镜入口打开独立截图配置，可沿用或更换截图，不依赖游戏前台状态。下拉磁贴仍按当前约定保留作测试入口。

## 手柄

- A 确认，B 取消或返回；方向键移动焦点。肩键切换页面时不会触发当前项目。
- Dashboard 只有四个操作按钮参与中区导航，映射依次为 `0` 文件管理、`1` 系统设置、`2` Odin 设置、`3` 滤镜调整。下移进入 Dock，上移可返回；顶部方向键可进入 CONFIG。统计区域不占焦点位置。
- Dock 的五张卡片都可按 A：性能循环默认、性能、高性能；风扇循环关闭、智能、高性能；摇杆灯与飞行模式切换开关；充电限制同时切换 80% 与 5V 档并分别显示读回状态。
- Dock 风扇聚焦时 X 切换“充电模式”，触摸副行同样可操作。A 手动选风扇档位会先停用充电策略，服务不会恢复旧的启动档位来覆盖手动选择。实际充电电流取决于电源与协商，5V 档不表示实测 3A。
- 滤镜滑条按 A 进入调节，左右修改，A 确认；B 取消并恢复进入时的值。选择弹层 A 确认、B 取消。之后 B 逐层收起高级参数、隐藏参数栏并退出页面。
- 滤镜仅在主层参数栏可见且高级参数未展开时允许 L1/R1 切换预设。按住 X 显示原图，按住 Y 隐藏参数栏，松开各自恢复之前状态；弹层内也支持。失焦、退出页面恢复临时状态，触摸开关继续可用。
- CONFIG 显示时，X/Y 不会叠出应用操作弹窗；B 返回当前页面。

## 数据与权限

所有统计在后台协程读取，首页先显示占位，不等待存储分类。Dashboard 可见时才采样，离开页面或桌面暂停后取消采集。内存总量、温度、外部卷及 Wi-Fi 约 2 秒更新，跨应用 PSS 约 15 秒，内置存储分类约 60 秒且单独缓存。没有 CPU/GPU 使用率或其备用采样任务。系统诊断子进程有等待时限及输出大小上限，不保存或打印诊断正文。

| 指标 | 口径 |
| --- | --- |
| 内置存储 | 系统总容量减去数据分区容量计为系统分区及保留空间；应用按 UID 去重统计代码与数据，缓存已含在数据中；其他为剩余已用数据。分类合计异常时不展示假比例。TF 卡不混入内置存储。 |
| 外部存储 | 枚举已挂载及只读挂载的非主卷，每卷单独显示名称、总量、已用和空闲；只读取文件系统容量元数据，不扫描文件、不创建目录。容量不可读取时保留卷卡片和原因，不填零。 |
| RAM | 总量与可用量来自 ActivityManager；使用量为总量减可用量。 |
| 非系统应用 | 当前用户、运行或缓存中的非系统应用进程 PSS；按 PID 统计，用 UID 对照应用 system flags，避免共享 UID 包重复。进程快照不完整或正在变化时等待下一次采样。 |
| CPU/GPU 温度 | 分别读取对应传感器的最高温，以数字和固定 0–105°C 温度条展示；不用电池温度或固定 40°C 代替，不显示使用率或频率。 |
| Wi-Fi | 从实际无线网络的 LinkProperties 选接口，分别计算接收/发送字节差值；换网与计数器重置时重新采样。名称遵守 Android 精确位置权限与系统定位开关限制。 |

应用存储分类需要使用情况访问权限。Android 15 的跨应用系统诊断还要求 `DUMP` 与 `PACKAGE_USAGE_STATS` 安装权限；这两个在上一版测试设备上属于可通过 ADB 授予的 development 权限。使用情况页面只开启 AppOps 并不等价于获得完整诊断权限。上一版曾为 `com.odin.desktop` 开通统计授权，新部署仍需检查实际授权；统计本身不依赖新的硬件桥。

如需重新部署到另一台设备，先确认序列号与包名，再按需授权：

```sh
adb -s SERIAL shell pm grant com.odin.desktop android.permission.DUMP
adb -s SERIAL shell pm grant com.odin.desktop android.permission.PACKAGE_USAGE_STATS
adb -s SERIAL shell cmd appops set com.odin.desktop GET_USAGE_STATS allow
```

Wi-Fi 名称受精确位置权限与系统定位开关限制，缺失时卡片只显示原因。需要时从“系统设置”进入权限或定位设置；程序不自动开启定位，统计卡片也不会跳转设置。

## 常用工具与硬件后端

系统文件管理优先打开 DocumentsUI Launcher/FilesActivity，不能用 PickActivity 目录选择器冒充文件管理；Odin 设置通过已解析的 `com.odin.settings/com.ro.settings.activity.MainSettingsActivity` 打开，避免依赖该应用不存在的 Launcher 入口。

Dock 的性能、风扇、灯光、充电与飞行模式现直接调用原厂 `PServerBinder`，保留固定操作与读回确认。服务启用与验证见 [原厂服务接入记录](hardware-standalone-investigation.md)。CPU/GPU、存储和内存统计保持既有数据路径；跨应用诊断权限要求仍按上文区分。下面的 ADB 桥记录属于 2026-09-04 历史版本。
