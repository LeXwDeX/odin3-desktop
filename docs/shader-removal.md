# 0.1.2：移除 Shader

用户在多个模拟器中遇到游戏画面接入失败，要求直接移除整个功能。本版本移除 Dashboard 的滤镜入口、快捷设置磁贴、校准和截图预览页面、运行引擎、前台目标识别回退、遮罩、渲染接口、GLSL 资源、专用文案及调试探针。当前 APK 不再提供游戏 Shader。

Dashboard 保留文件管理、系统设置、Odin 设置三个操作。默认桌面注册、底部硬件 Dock、顶部电池/风扇区域、语言选择、方向规则和息屏挂机保留。风扇使用的前台应用监控和挂机使用的悬浮窗权限也保留。

## 升级数据

数据库从版本 4 升级到 5，只删除 `app_shader_configs`；保留原有分类、排序、默认首页、游戏分类标记、图标、应用映射、自定义名称、隐藏标记和自增 ID。保留此前的迁移链，以便更早版本也能升级。全新安装不创建 Shader 配置表。

同签名 APK 可覆盖升级，无需卸载或清数据。旧版私有目录内的截图预览副本和偏好不再读取；不会访问或删除用户的原始截图、游戏或存档。

旧版说明和第三方许可证作为历史记录保留，并明确标注退役。方向测试仍使用独立测试包，工具迁至 [device-validation](../tools/device-validation/README.md)，不作为主应用依赖。
