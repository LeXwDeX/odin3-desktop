# 中文、英文、日文与 CONFIG 语言选择

默认选择“跟随系统”。设备系统语言匹配中文、英文或日文时使用对应文案；没有匹配语言时使用完整英文资源。中文目前统一使用简体文案，`zh-CN` / `zh-SG` / `zh-TW` / `zh-HK` 都会匹配中文；尚未提供独立的繁体翻译。

进入 **CONFIG（设置）→ 5. 语言**，可选择：

| 选项 | 行为 |
| --- | --- |
| 跟随系统 | 清除应用语言覆盖，继续响应设备的系统语言变化 |
| 中文 | 固定使用中文 |
| English | 固定使用英文 |
| 日本語 | 固定使用日文 |

触屏点击即可切换；手柄在左侧选择“语言”，按右键或 A 进入，使用上下键选择、A 确认，B 返回。语言名称始终使用各语言自己的写法，误选后也能找到熟悉的选项。左侧菜单与语言选项支持滚动，手柄焦点会进入可见区域。切换会刷新界面，CONFIG 的位置与状态由保留的 ViewModel 继续持有。

## 实现约定

- `AppLanguage` 通过 `AppCompatDelegate.setApplicationLocales` 设置语言，空 locale 列表表示跟随系统。Android 13+ 使用系统应用语言设置并与系统设置页同步；Android 10–12 使用 AndroidX 的 `autoStoreLocales` 持久保存。
- 桌面 MainActivity 使用 `AppCompatActivity` 和兼容的无操作栏主题。Android 10–12 的 Application、息屏入口、通知服务与磁贴使用 `AppLanguageContext`，启动时恢复保存的语言，避免界面语言与后台文案不一致。缓存的资源随语言和系统配置变化失效；切换后通知、频道与磁贴刷新文字。
- `values/strings.xml` 是英文兜底；`values-b+zh+Hans` 和 `values-b+zh+Hant` 使用同一套中文文案；`values-ja` 包含完整日文。各语言的文案键与格式参数由回归脚本检查，另外 3 条语言名称标记为不翻译。
- `locales_config.xml` 声明三种应用语言；Gradle 限制 APK 中的语言资源，避免依赖库携带的其他语言影响语言匹配。App Bundle 关闭语言拆分，三种语言随安装包提供，支持离线切换。
- 分类身份、排序、应用映射和用户输入的名称保持独立于展示语言，Shader 移除时的数据库升级只删除其专用配置表。

API 依据见 [Android 应用语言文档](https://developer.android.com/guide/topics/resources/app-languages?hl=en)。

## v0.1.7 紧凑 UI 文案

底部快捷栏使用独立 `dock_*` 展示资源。英文和日文性能档为 P1/P2/P3，风扇为 OFF/S/M，兼容 Q（静音）、SYS（原厂其他档位）和 —（未读取）；中文保留短中文标签。其他快捷项缩短为图标配 ON/OFF、充电电压/电流及 BP（充电分离）。原始完整名称用于无障碍描述，代号不改变硬件模式和读回含义。

Tab 上移/下移按钮统一显示 ▲/▼，保留本地化无障碍说明；名称与操作分行，操作文字可在可用宽度内换行。弹窗标题给右侧返回说明预留空间。README 统一使用英文说明和英文实机截图，用户自定义分类与第三方应用名称不为截图改写。

## v0.1.11 默认桌面布局与分类原名

默认桌面设置卡片将标题、状态、说明和操作按钮分行，每项独立使用卡片宽度，避免英文和日文的状态标签被相邻文字挤成多行。卡片点击与手柄 A 的原有动作保持不变。

历史 3→4 迁移曾按 ID 和名称将已有“游戏与模拟器”“系统工具”等分类标为 `usesDefaultName=true`，原名仍保存在数据库中。显示层现在优先采用这些已保存的名称，不再用翻译覆盖；顶部分类也不再强制大写。无需改写数据库、分类 ID、排序或应用归属。

“全部应用”仍是系统入口，保留其默认名称时随界面语言翻译；明确改名后按原文显示。没有存储名称的系统种子分类继续使用资源名称。新增回归覆盖中、英、日环境下的历史默认标记、混合大小写、自定义名称和系统入口翻译。
